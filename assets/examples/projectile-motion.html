🎯 Projectile Motion — Interactive Physics Simulation

Explore launch angle, initial speed, range, maximum height, and time of flight. Watch how the trajectory is built from two completely independent motions acting simultaneously.

⚡ Common Misconception — and the Truth: Many students think that moving horizontally somehow changes how fast something falls, or that the horizontal speed slows down because of gravity. This simulation proves otherwise: the blue (horizontal) arrow stays exactly the same length throughout the entire flight, while the red (vertical) arrow grows steadily downward. Gravity affects only the vertical component — the two motions are completely independent.

Key Equations
Horizontal velocity
vₓ = v₀ cosθ
Vertical velocity
v_y = v₀ sinθ − g·t
Horizontal position
x = vₓ · t
Vertical position
y = y₀ + v₀sinθ·t − ½g·t²
Time of flight (y₀=0)
T = 2v₀sinθ / g
Maximum height
H = (v₀sinθ)² / (2g)
Range (y₀=0)
R = v₀² sin(2θ) / g
Speed at any time
|v| = √(vₓ²+v_y²)
