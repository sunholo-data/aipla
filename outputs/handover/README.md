# Handover package

Task-oriented runbooks written *for* the two postdocs — **AR** (co-PI, present now)
and **AD** (starts ~1 Oct; no in-person overlap with M, so these documents carry the
handover). Started 2026-07-10; target complete before the contract ends 2026-09-15.

Style rule: each runbook is a task recipe a reader can follow without M in the room —
prerequisites, steps against the real repo/console, verification, and what failure
looks like. Content is filled in from the execution repo (`cphu-aipla-app`), not from
design docs.
